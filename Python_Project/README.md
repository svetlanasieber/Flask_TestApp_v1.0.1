## 📝 Описание

Мултиплатформен калкулатор, разработен на Python, демонстриращ различни подходи за разработка на потребителски интерфейси. Проектът включва три различни имплементации на калкулатор:

1. **Конзолен калкулатор** - класически текстов интерфейс
2. **GUI калкулатор** - графичен интерфейс, използващ Tkinter
3. **Уеб калкулатор** - модерен интерфейс, достъпен през браузър

Всички имплементации споделят една и съща логика за изчисления, показвайки как базовата функционалност може да бъде адаптирана за различни потребителски интерфейси.

## 🛠️ Използвани технологии

### Бекенд
- **Python** - основен програмен език
- **Flask** - лек уеб фреймуърк за Python
- **Tkinter** - стандартна библиотека за GUI в Python

### Фронтенд (Уеб версия)
- **HTML5** - структура на уеб интерфейса
- **CSS3** - стилизиране и анимации
  - Използване на модерни CSS техники: Glass Morphism, анимации, градиенти
  - Респонсивен дизайн
- **JavaScript** - клиентска логика и интерактивност
  - Fetch API за комуникация със сървъра
  - DOM манипулации
  - Събития и обработка на потребителски вход

### Архитектурни принципи
- **Разделяне на бизнес логика и потребителски интерфейс**
- **Модулна структура** - преизползване на основната логика за изчисление
- **REST API** - за комуникация между фронтенд и бекенд при уеб версията

## 🚀 Инсталация и стартиране

### Предварителни изисквания

- Python 3.x
- pip (Python Package Installer)

### Стъпки за инсталация

1. Клонирайте хранилището:
   ```bash
   git clone https://github.com/your-username/python-calculator.git
   cd python-calculator
   ```

2. Инсталирайте зависимостите:
   ```bash
   pip install -r requirements.txt
   ```

### Стартиране на различните версии

#### Конзолен калкулатор
```bash
python calculator.py
```

#### GUI калкулатор
```bash
python gui_calculator.py
```

#### Уеб калкулатор
```bash
python web_calculator.py
```
След стартиране на уеб сървъра, отворете http://127.0.0.1:5000/ в браузъра си.
